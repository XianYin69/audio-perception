# 谱栅格与 tokens 读法

`analyze.py` 除数值特征外还产出两种"可读写"表示，是模型判读的主要依据。
字段语义见 [声学特征字典](声学特征字典.md)。

## spectrogram_grid（16×24 ASCII）

16 时间帧 × 24 对数频段，log 能量按全局 min/max 量化到 ` .:-=+*#%@`
（空格最静、@ 最响）。渲染时高频在上、低频在下，时间从左到右。

- 水平亮线＝稳态纯音或谐波族；多条等距水平线＝乐器、引擎。
- 垂直亮柱＝瞬态冲击（撞击、鼓、枪）。
- 上宽下窄的斜线＝扫频（警报、鸟鸣、哨声）。
- 全带均匀灰＝噪声（风、水、环境底噪）。
- 亮线随时间起伏＝调制（警笛 0.5-2Hz、语音音节 3-8Hz）。
- 只有下方几行亮＝低频为主（雷、引擎、远处交通）。

注意：栅格是**粗量化**（24 频段、16 帧），不能据此断言精确频率或精确时刻；
需要精确值时读 `spectral_centroid_hz`、`f0_hz`、`rolloff85_hz` 等数值字段。

## tokens 行

`--format tokens` 输出一行紧凑编码，供提示词摘要与批量表使用：

```
A:RMS-15|CEN1357|F0=615|ON=15|FLAT0.00|ZCR0.08|DYN17|BPM46|CHR[.0,.0,.04,1.0,...]
```

| 记号 | 字段 | 记号 | 字段 |
|---|---|---|---|
| RMS | rms_dbfs | FLAT | spectral_flatness |
| CEN | spectral_centroid_hz | ZCR | zcr_mean |
| F0 | pitch.f0_hz | DYN | dynamic_range_db |
| ON | onset_rate_hz | BPM | bpm |
| CHR | chroma 12 维 | | |
