# 声音类别体系

14 类（perceive 的 type.primary 只能从中选）＋判别锚点。锚点引用
[声学特征字典](声学特征字典.md) 的字段名。置信度不足时降 confidence 并写进 uncertainty。

| primary | sub 示例 | 判别锚点 |
|---|---|---|
| 语音 | 男/女/多人/电话 | 谐波族+2-4kHz 共振峰+起音 3-8Hz；f0 85-255；flatness<0.2 |
| 人声非语言 | 笑/哭/咳嗽/喊 | 语音类谐波但轮廓剧烈、glissando 高、动态范围大 |
| 音乐 | 弦/管/打击/电子 | 稳定 f0+整数谐波族+BPM 60-180+inharmonicity 低 |
| 动物 | 犬/猫/鸟/昆虫 | 鸟=2-8kHz 快调频谐波；昆虫=窄带高频稳态；犬=低 f0 冲击起音 |
| 自然 | 风/雨/雷/水 | 风=低频宽谱无谐波+flatness>0.5；雷=低频冲击+长尾；雨=中高频均匀噪声 |
| 交通载具 | 车/火车/飞机/船 | 引擎=低基频+整数谐波族+慢漂移；驶过=多普勒包络 |
| 机械工具 | 电钻/锯/缝纫 | 稳周期谐波+高 voiced_confidence+固定 f0 或固定调制 |
| 冲击碰撞 | 敲门/掉落/碰撞 | 毫秒级起音+宽频+指数衰减+onset 稀疏 |
| 电子提示音 | 蜂鸣/ beep/ 铃声 | 极窄带+flatness≈0+时长<1s+无谐波漂移 |
| 警报 | 警笛/火警/倒车 | 稳周期 0.5-2Hz 调制+窄带+高质心+glissando 明显 |
| 环境底噪 | 空调/办公室/街道 | 低动态+高 flatness+无 f0+包络方差近 0 |
| 爆炸枪声 | 枪/爆/烟花 | 峰值≈0dBFS+clipping_ratio 高+毫秒起音+低频能量突增 |
| 流体 | 倒水/流水/沸腾 | 中频带噪声+气泡起音簇+连续无谐波 |
| 摩擦接触 | 玻璃/金属/木/织物 | 玻璃金属=极高质心+窄带+强谐波；织物=低质心宽谱噪声 |

## 优先级与冲突

- 谐波性（flatness<0.1 且 voiced_confidence>0.4）优先判：语音/音乐/动物/机械/警报/电子提示音。
- 噪声性（flatness>0.4）优先判：自然/环境底噪/流体/摩擦。
- 瞬态（onset 稀疏+毫秒起音+指数衰减）优先判：冲击碰撞/爆炸枪声。
- 混合场景（如语音+底噪）取能量占比高者为 primary，另一写进 sub 与 evidence。

## 阈值来源与复标（诚实声明）

上表锚点区间由**合成样本**（正弦谐波族、白噪声、指数衰减脉冲）实测标定，
未经真实语料统计验证，可能存在系统性偏移。使用真实录音发现偏差超过一档时，
须更新本表并记入 CHANGELOG（已挂计划任务
`pt-audio-perception-recalibrate`，到期由 SMS 调度器提醒）。

因此 confidence 的合理上限：仅凭编码特征判到 sub 级＝0.7；判到具体声源名（top3）＝0.6；
任何超出 14 类粒度的断言一律 ≤0.4 并写进 `uncertainty`。
