# 声学特征字典

编码字段 → 含义 → 判读线索。全部由 `scripts/analyze.py` 确定性产出（同输入同输出）。
配套：[声音类别体系](声音类别体系.md)、[谱栅格读法](谱栅格读法.md)、[WAV解码注意](WAV解码注意.md)。

## meta / loudness

- duration：秒。<0.3s 多为单击或提示音。
- sample_rate/channels/bit_depth：8k≈电话语音，44.1k/48k≈通用。
- clipping_ratio：|x|≥0.995 占比。>0.01 提示爆音、枪声、强冲击。
- is_silence：silence_ratio>=0.95 时为 true，此时频域特征与 onset/bpm 全置 0（空谱均值会误导判读）。
- silence_ratio：20ms 块 RMS<0.01 的占比。高=断续事件声。
- rms_dbfs / peak_dbfs：-60 极静，-20 常态，-6 很响。
- dynamic_range_db：包络 P95-P10。大=起伏强（音乐/语音），小=稳态（引擎/底噪）。
- envelope_var：近 0 = 稳态音。

## time

- zcr_mean/zcr_std：过零率。>0.25 噪声性（风/摩擦）；<0.1 谐波性（音高类）。
- onset_rate_hz：20ms 块能量包络正差分去噪声底（flux 的 60 分位基线＋3×MAD）后，取「局部峰 且 env>1.41×中位包络」的显著峰次数/秒。3-8Hz≈音节率；0.5-2Hz≈警笛调制；稳态音应 <2。
  瞬态兜底（现状，已不限时长）：rise＝1ms 块 RMS 的峰值 10%→90% 上升毫秒；冲击形态＝rise≤10ms 且 峰值>0 且 median(1ms 块 RMS)<0.2×峰值；命中冲击形态（任意时长）或 dur<0.15s 且 rise<10ms 时取 max(计数值, 1/dur)。只抬升不降低；稳态音（median≥0.2×峰值）与 rise>10ms 不触发；长输入下 1/dur 极小（8s→0.125Hz）故不会伪造高起音率；is_silence 时置 0。
- bpm：节拍＝20ms 块 RMS 能量包络的调制周期（自相关取峰，30-300 BPM 带内），**时间基是块能量调制，不是起音间隔、也不是帧移 hop_s**。判据：块数≥8（≥160ms）、调制深度 std/mean≥0.05、自相关峰≥0.3，任一不达标＝0（稳态音 cv≈0.006→0）。量化 20ms→120BPM 处 ±1 块＝115.4/125.0；带外节拍被拉回带边（实测 28/32/290/310→300.0），须与 onset_rate_hz、duration 交叉复核。60-180 且方差小≈音乐。
- hop_s：帧移秒数（HOP=512）。

## spectral

- spectral_centroid_hz：<500 低沉；2-4k 语音共振峰区；>6k 玻璃/金属摩擦。
- spectral_bandwidth_hz：窄=纯音/警报；宽=撞击/噪声。
- rolloff85_hz：85% 能量以下的频率，指示高频能量占比。
- spectral_flatness：几何均值/算术均值。>0.5 噪声性；<0.1 谐波性；>0.4 时 f0 强制置 0。
- spectral_skewness / spectral_kurtosis：谱形状；尖峰=共振明显。
- band_contrast：7 个对数等分带的平均 log 能量，带间落差=音色倾斜。

## pitch / mel / chroma

- f0_hz：基频（50-4000Hz），候选=离散谱峰＋ACF 子倍频，须过谐波校验。男声 85-180，女声 165-255。
- voiced_confidence：(1-平坦度)×min(1, 谐波占比/0.5)。>0.5 清音；<0.2 噪声。
- harmonic_ratio：f0 整数倍谐波族能量占比；<0.3 视为无谐波族（噪声）→ f0=0。
- pitch_contour_std_cents：大=旋律/哭喊；小=稳调。
- glissando_cents_per_s：高=警报扫频、鸟鸣快调频。
- inharmonicity：1-谐波能量占比。低=乐器/语音；高=金属、撞击。
- mfcc_mean / mfcc_std：40 mel→log→DCT 的 13 维。c1≈响度，c2-c4≈谱倾斜。
- mel_energy_mean_db：40 带平均 log 能量＝谱包络形状。
- chroma：12 音级强度（帧最大值归一）。单峰=纯调；平坦=非乐音。
- tokens：一行紧凑编码串，见 [谱栅格读法](谱栅格读法.md)。
