# 网关文本调用

本技能只有文本通道：模型不接收音频字节，只接收 `analyze.py` 产出的编码文本。

## 配置来源（唯一）

`<SMS_HOME>/config/config.json` 的 `llm_gateway` 段（SMS_HOME 默认
`%LOCALAPPDATA%\SMS`）。`scripts/_cli.py:gateway_cfg()` 直读该文件——
不复制、不重建、不写回；缺失或 `base_url` 为空即退出。

- base_url：`https://api.scnet.cn/api/llm/v1`（OpenAI 兼容）
- 端点：`POST {base_url}/chat/completions`
- 鉴权：`Authorization: Bearer <api_key>`
- 采样参数沿用配置：model / max_tokens / temperature / top_p / timeout

## 调用范式

`_cli.chat_text(messages, max_tokens)` 用标准库 `urllib.request`（零额外依赖），
messages 为纯文本 `[{role:system},{role:user}]`，无 audio/image 通道。
返回 `{reply, usage, model}`。

## 红线

- api_key 绝不打印、绝不写入任何产物文件、绝不进日志与异常文本。
- 失败即停：HTTPError/URLError/JSONDecodeError 直接退出，不重试、不改参数再打。
- 判读结果里的 `usage` 只回填 model/prompt_tokens/completion_tokens 三个非敏感字段。
- 范式出处：`local://screen-vision` 的 `scripts/gw.py`（同读法、同不打印 key）。

## 提示词契约

system 段（`perceive.py:SYSTEM`）内嵌 14 类体系与锚点（见
[声音类别体系](声音类别体系.md)），并强制"只输出 JSON、无围栏"。
user 段＝`analyze.render_text(enc)` 全文（含 ASCII 谱栅格）＋可选 `--hint`。
