# 失败即停不重试

## 规则

1. 解码失败、特征计算失败、网关 HTTP/网络/JSON 错误：打印原因后 `exit`，
   不改参数、不换模型、不循环重打。
2. 允许的"再试一次"只有两类：
   - 本地解析容错（剥围栏 → 括号平衡扫描 → 截断抢救 `_salvage_json`），不再调网关；
   - **唯一网关重试例外**：`finish_reason=="length"` 且抢救失败时，追加
     「只输出压缩 JSON，evidence≤3 条」再调一次，仅限一次；抢救成功则不重试。
3. 批量模式：单文件失败记入 `errors` 并继续下一个，整批退出码 1；
   不得对同一文件重复请求网关。
4. 熔断：同类错误连续出现即中止并转人工，不自创降级路径（如偷偷换 base_url）。
5. 失败输出必须可诊断：包含文件路径、失败阶段（decode/encode/gateway/parse）。

## 降级顺序（允许）

- 网关不可用 → 只交付编码（`analyze.py --format json`），判读留待用户重跑。
- 无录音后端 → `exit 2` 并给手动安装命令，不降级到猜测。
- 非 WAV → 给 ffmpeg 命令模板，不代转。

## 违规后果

- 重试风暴打爆网关配额、放大故障（故 length 例外只许一次，且仅限输出截断）；
- 静默降级产出看似成功实则编造的结果。
