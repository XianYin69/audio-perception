# 不夸大识别率

## 规则

1. 证据不足必须降置信度：`type.confidence <= 0.5` 时 `uncertainty` 不得为空。
2. 禁止编造：网关没给的字段填空值/空数组，不猜测补齐（`perceive.normalize()`）。
3. 禁止把"编码相似"说成"确认听到"；`evidence` 必须引用真实特征名与特征值。
4. 细粒度千类声事件（AudioSet 级）不可靠：只给 14 类 primary＋sub，
   需要更细粒度时在 `uncertainty` 写明所需额外能力（如专用分类模型）。
5. 语音内容（说了什么）需 ASR，本技能不含：只判"是语音＋情绪"，不得转写。
6. 说话人身份、性别年龄的精确判断、超采样率上限的高频成分，一律不得断言。
7. 对外表述用"判读/推测"，不用"识别准确率为 X%"这类无基准的数字。

## 违规后果

- 高置信度幻觉误导下游决策（安防、质检、辅助听障场景后果尤重）；
- 用户误信转写或身份判断，造成隐私与合规风险；
- 结果不可复现，破坏本技能"以 evidence 为准"的契约。
