# 不写技能目录外缓存

## 规则

1. 所有产物（编码 JSON、判读 JSON、录音 WAV、批量汇总）一律落工作区 tmp：
   `env SMS_TMP`，缺省回退 `%TEMP%\audio_perception`（`_cli.tmp_dir()`）。
2. 技能目录内只允许版本化内容：SKILL.md、agent/、branch/、scripts/、knowledge/、
   resistance/、schemas/、dependence/、planned_tasks/、asset/、update/、LICENSE 等。
3. 缓存文件、`__pycache__/`、录音样本、用户音频一律不得写入技能目录。
4. 不写 SMS 配置：`config/config.json` 只读（`gateway_cfg()`），不复制、不重建、不回填。
5. 用户音频文件本身不搬迁、不改写；转码产物须用户显式指定输出路径。

## 违规后果

- 技能目录被样本污染 → 打包/注册体积失控、隐私外泄；
- 写配置会破坏 SMS 单一事实源，导致网关参数漂移；
- 缓存散落各处 → 垃圾回收无法定位，tmp 无限增长。
