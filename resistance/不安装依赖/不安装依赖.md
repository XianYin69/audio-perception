# 不安装依赖

## 规则

1. 本技能任何脚本不得调用 `pip install`、`winget install`、`choco` 或任何包管理器。
2. 缺包只报错：`deps.require()` 打印缺哪个模块＋手动命令建议，`exit 2`。
3. 硬依赖只有 `numpy`（已装 2.5.2 / Python 3.14.5）；FFT 用 `numpy.fft`，
   mel 滤波器组与 DCT 手搓，不得 import librosa/scipy/soundfile/pydub/torchaudio。
4. 录音是可选能力：sounddevice → pyaudio → ffmpeg dshow 依次探测，
   全不可用时 `capture.py` 打印精确安装命令并 `exit 2`，绝不代装。
5. 非 WAV 输入只给 ffmpeg 转码命令模板（见 knowledge/WAV解码注意.md），不代转不代装。
6. `audioop` 在 Python 3.13 已移除，禁止引用。

## 违规后果

- 静默装包污染用户环境、可能装到不可信版本；
- 依赖未声明即 import，换机即崩，且违反 deps.json 契约；
- 自动安装属高危动作，未经用户拍板不得执行。
